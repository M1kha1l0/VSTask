# VSTask
## Обзор

VSTask - это расширение для Visual Studio Code, которое предоставляет простой и удобный трекер задач прямо в вашей среде разработки. Создавайте, редактируйте и удаляйте задачи, не покидая редактор кода.

## Функциональность

### Основные возможности
- **Создание задач**: Добавление задач с заголовком, описанием, приоритетом и дедлайном
- **Система приоритетов**: Приоритеты от 1 (низкий) до 10 (высокий)
- **Умные дедлайны**: Автоматическое определение просроченных задач и повышение их приоритета
- **Автоматическая сортировка**: Задачи автоматически сортируются по убыванию приоритета
- **Просмотр задач**: Список всех задач в панели активности с визуальными индикаторами
- **Редактирование задач**: Изменение существующих задач через модальное окно
- **Удаление задач**: Удаление ненужных задач с подтверждением
- **Сохранение состояния**: Все задачи сохраняются между перезапусками VS Code

### Интерфейс
Расширение добавляет новую панель в Activity Bar с иконкой задач. Интерфейс состоит из:
- **Форма добавления задачи**: Поля для заголовка, описания, приоритета и дедлайна
- **Список задач**: Отображение всех созданных задач, отсортированных по приоритету
- **Визуальные индикаторы**: Цветовое кодирование для просроченных задач и задач с дедлайном
- **Кнопки действий**: Редактирование и удаление для каждой задачи
- **Модальное окно редактирования**: Для изменения существующих задач

## Использование

### Как запустить
- Скачать пакет расширения VScode.
- Выполнить `code --install-extension vsc-task-X.X.X.vsix`
  
### Открытие панели задач
1. Нажмите на иконку VSTask в Activity Bar (левый сайдбар)
2. Или выполните команду: `Ctrl+Shift+P` → "VSTask: Show View"

### Добавление задачи
1. Введите заголовок задачи в поле "Task title"
2. (Опционально) Добавьте описание в поле "Task description"
3. Установите приоритет (от 1 до 10) в поле "Priority"
4. (Опционально) Установите дедлайн, выбрав дату и время
5. Нажмите кнопку "Add Task"

### Редактирование задачи
1. Нажмите на иконку редактирования (карандаш) рядом с задачей
2. В модальном окне измените заголовок, описание, приоритет или дедлайн 
3. Нажмите "Save" для сохранения или "Cancel" для отмены

### Удаление задачи
- Нажмите на иконку удаления (корзина) рядом с задачей
- Задача будет немедленно удалена с показом уведомления

## Хранение данных
Все задачи сохраняются в глобальном состоянии VS Code (`context.globalState`), что означает:
- Задачи сохраняются между перезапусками VS Code
- Задачи доступны во всех рабочих областях
- Данные хранятся локально на вашем компьютере

### Архитектура
Расширение использует:
- **Webview API** для отображения пользовательского интерфейса
- **Global State** для хранения данных
- **Event Emitter** для обновления интерфейса
- **QuickSort** для эффективной сортировки задач по приоритету
- **Система таймаутов** для отслеживания дедлайнов в реальном времени
